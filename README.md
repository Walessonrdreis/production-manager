# Sistema de Gerenciamento de Produção

## Sobre o Projeto
Sistema completo para gerenciamento de produção industrial, desenvolvido com tecnologias modernas para garantir eficiência, escalabilidade e facilidade de uso.

## Tecnologias Utilizadas

### Backend
- Node.js + Express.js
- TypeScript
- PostgreSQL
- Prisma ORM
- JWT Authentication
- Jest

### Frontend
- React
- Next.js
- TypeScript
- Tailwind CSS
- React Query
- Axios
- Vitest

## Funcionalidades Principais
- Gestão de usuários e autenticação
- Gestão de produtos e matéria-prima
- Controle de estoque
- Planejamento de produção
- Ordens de produção
- Monitoramento em tempo real
- Relatórios e dashboards
- Gestão de fornecedores
- Controle de qualidade
- Rastreabilidade de lotes

## Estrutura do Projeto
```
production-manager/
├── backend/         # API REST com Node.js
└── frontend/        # Aplicação Next.js
```

## Como Iniciar o Desenvolvimento

### Requisitos
- Node.js 18+
- PostgreSQL 14+
- npm ou yarn

### Configuração do Backend
```bash
cd backend
npm install
npm run dev
```

### Configuração do Frontend
```bash
cd frontend
npm install
npm run dev
```
